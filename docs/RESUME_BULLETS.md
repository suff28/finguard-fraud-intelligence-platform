# Resume Bullets

- Built a real-time fraud detection data platform using Kafka-compatible Redpanda, Python, PostgreSQL, Redis, FastAPI, Docker, and Streamlit to process simulated credit card transaction streams.
- Designed a streaming data pipeline that validates transactions, engineers fraud-risk features, scores suspicious activity, stores results in PostgreSQL, and surfaces alerts through API and dashboard layers.
- Implemented fraud signals for high transaction amount, risky merchant categories, card-not-present transactions, high-risk countries, night-time activity, and suspicious device patterns.
- Created a Docker Compose architecture with separate services for transaction generation, stream consumption, fraud scoring, PostgreSQL storage, Redis alert caching, API access, and dashboard visualization.
